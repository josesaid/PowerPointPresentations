## What is Spring AI?

[Spring AI](https://spring.io/projects/spring-ai) is a Spring Framework project designed to simplify the integration of artificial intelligence into Java applications. It provides a consistent, portable API across leading AI providers — including OpenAI, Anthropic, Google Vertex AI, and others — so developers can swap models without rewriting business logic.

### Key topics covered in this presentation

- **AI Models & Providers** — connecting to LLMs via a unified abstraction layer
- **Prompt Engineering** — structured prompts, templates, and system messages
- **Chat & Completion APIs** — building conversational AI features in Spring Boot
- **Embeddings & Vector Stores** — semantic search and document retrieval
- **Retrieval-Augmented Generation (RAG)** — grounding AI responses in your own data
- **Function Calling / Tool Use** — giving models access to application logic
- **Advisors** — cross-cutting concerns for AI interactions (logging, memory, guardrails)
- **Spring Boot Autoconfiguration** — zero-boilerplate setup for AI clients
